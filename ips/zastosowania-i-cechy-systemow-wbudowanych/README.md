# Zastosowania i cechy systemów wbudowanych

## 1. Definicja
* **System wbudowany:** wyspecjalizowany system komputerowy, który jest integralną częścią innego urządzenia/maszyny/systemu. 
* Opiera się na mikroprocesorze, mikrokontrolerze, PLC lub komputerze jednopłytkowym. 
* Często działają w czasie rzeczywistym
* W przypadku bardzo zaawansowanych moe być oparte na zwykłym komputerze. 
* Wykonuje ściśle zdefiniowane zadania. 


## 2. Cechy systemów wbudowanych
* zintegrowane wewnątrz systemu
* niezawodność, stabilność działania
* energooszędność
* praca w czasie rzeczywistym
* ograniczone zasoby sprzętowe
* dedykowane oprogramowanie
* często brak interfejsu


## 3. Zastosowania systemów wbudowanych
* motoryzacja (sterownik silnika (ECU-engine control unit))
* elektronika domowa (intelignte pralki itp.)
* automatyka przemysłowa (linie produkcyjne, roboty)
* telekomunikacja (modem, router)
* medycyna (aparatura, rozrusznik, pompa insulinowa)
